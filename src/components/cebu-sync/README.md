# Cebu Sync — Phase 1（簡易版）

セブ島オフィス（スタッフ5名・管理者不在）を日本から遠隔管理するための業務マネジメント Web アプリのプロトタイプ。

- `CebuSync.tsx` — 単一ファイルの React + TypeScript コンポーネント（Tailwind CSS / lucide-react）。default export `CebuSyncApp`。
- 外部依存は `react` と `lucide-react` のみ。データはすべてメモリ上のモック（GPS・Teams・CSV はシミュレーション）。
- Claude Artifacts（React）にそのまま貼り付けてプレビューできます。

## 起動方法

Next.js アプリの `/cebu-sync` ページとして組み込まれています（ログイン不要・全幅表示）。

- Vercel: デプロイ（プレビュー）URL の末尾に `/cebu-sync` を付けて開く
- ローカル: `npm run dev` → http://localhost:3000/cebu-sync

Family SNS のスマホ枠レイアウト・ログイン画面とは別にするため、`src/app/(family)` と `src/app/(cebu)` の 2 つのルートグループに分け、それぞれにルートレイアウトを置いています（URL は従来どおり）。

| タブ | 内容 |

| 📌 Tasks & Approval | タスク一覧・マイルストーン・遅延検知・ワンタップBlocker申告・証跡添付、GM/HQO承認トレイ、＋Add Task |

## 言語切り替え（英語／日本語）

ヘッダーの `🌐 EN | 日本語` ボタンで UI 全体をワンタップで切り替えられます。現地スタッフ（Staff）に切り替えると英語、GM / HQO に切り替えると日本語が既定になり、その後はいつでも手動で切り替え可能です。

- 画面の文言は `L('English', '日本語')`、データ側の文言は `Bi`（`{ en, ja }`）で持ち、`T()` で表示言語に変換します。
- スタッフが入力したタスク名・コメントなどは入力した言語のまま表示します（自動翻訳はしません）。

## スタッフ設定（GM / HQO のみ）

ロールバーで GM / HQO に切り替えると「⚙️ Staff Settings / スタッフ設定」タブが表示されます。

- スタッフ名の編集、ROLE（担当）タグの付け外し（1人で何個でも兼任可・複数人で同じ ROLE も可）、保存
- カスタム ROLE タグの追加・削除（既定: HR & Admin / Accounting & BIR / Academic & Lessons / External Visits / Facilities & IT / Teacher Management）
- スタッフの追加・無効化・再有効化（無効化したスタッフはロールバーや担当者候補から外れ、過去タスクの担当者名は残ります）
- 保存内容は上部バー・ダッシュボード・タスク詳細・時間割に即時反映。タスク起票では大分類に合う ROLE を持つ人、時間割・Teams 予約では教務 / 講師管理 ROLE を持つ人に ★ が付きます

## 学年マーク（生年月日から自動判定）

- 学生登録・一覧の編集（✏️）で生年月日を入力すると、日本の学年制度（4月1日区切り・早生まれ考慮）で学年マークを自動計算します（`gradeTagFromDob`）
- 現在の学年度 = 今日が4月1日以降なら今年、1〜3月なら前年。1月1日〜4月1日生まれは誕生年度を「誕生年 - 1」とし、学齢差 = 現在の学年度 − 誕生年度
- 学齢差 4以下 Nursery / 5 K1 / 6 K2 / 7〜12 E1〜E6 / 13〜15 JH1〜JH3 / 16〜18 H1〜H3 / 19以上 Adult
- 学年マークは保存せず表示のたびに計算するため、年度が替わると自動で進級します。学生一覧・対面タイムテーブル・本日のマイルストーン・Teams 予約の生徒名の横に表示します

## 対面授業のタイムテーブル

- 標準コマ（各50分・昼休憩 12:00〜13:00）: Slot 1 08:00 〜 Slot 9 17:00。生徒登録時の受講時間帯（08:00〜18:00）に収まるコマが受講対象（例: 08:00〜17:00 なら 8コマ）
- 日付と生徒を選ぶと、受講期間内であればその生徒のコマだけが表に並び、各コマで科目（科目マスター）と担当講師を選べます
- 同じ日・同じコマで別の生徒を担当中の講師は「(Busy)」表示で選べず、万一選ばれてもエラー表示で拒否します
- 講師をアサインすると、その日が今日ならその講師の「本日のマイルストーン」に自動追加されます
- 科目マスター（初期: Speaking / Listening / Reading / Writing / Vocabulary / Grammar / Pronunciation / Business English）は、生徒・レッスンタブ（Staff を含む全ロール）と GM / HQO のスタッフ設定タブのどちらからでも追加・削除できます（同じデータ）

上部のロールバーで `👤 Staff`（▾でスタッフ切替）/ `👔 GM` / `🏦 HQO` を1クリックで切り替えられます。
