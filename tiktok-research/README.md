# TikTok リサーチ（個人用）

公開TikTokアカウントの **リサーチ（分析）** と **動画のダウンロード** だけに絞った、自分専用のWebアプリです。
元のWordPressページにあった広告・ショップ・問い合わせ・解析タグ（Cloudflare Insights 等）・Cookie・外部フォント／CDNはすべて取り除き、ゼロから作り直しています。

## できること

| 機能 | 内容 |
| --- | --- |
| アカウントを調べる | ユーザー名 / プロフィールURL を入れると、プロフィール（名前・認証・自己紹介・フォロワー・いいね・投稿数）を表示 |
| リサーチ結果 | 読み込んだ投稿から、平均・中央値の再生数、エンゲージメント率、再生÷フォロワー、投稿ペース（週あたり）、平均の長さ、再生数の推移グラフ、投稿の曜日・時間帯、よく使うハッシュタグ（回数・平均再生）、再生数トップ5 |
| 投稿一覧 | 並び替え（新しい順・再生数・いいね・コメント・シェア・エンゲージメント率）、タイトル／#タグで絞り込み、「動画のみ」、30件ずつ／全件（最大1000件）読み込み |
| CSV出力 | 表示中の投稿を Excel で開ける CSV に保存 |
| ダウンロード | 透かしなしHD動画・標準画質・透かしあり・音声MP3・写真投稿の画像。1本ずつ／「表示中をすべて保存」で順番にまとめて保存（進み具合の表示・中止あり） |
| 動画1本 | 動画URL（`vm.tiktok.com/…` の短縮URLも可）を入れると、その動画だけを保存 |

非公開アカウントは、公開されているプロフィール情報だけ表示し、動画の取得はしません。

## しくみ

- データは [tikwm.com](https://www.tikwm.com) の公開APIから取得します（無料枠は「1秒に1回」なので、サーバー側で自動的に間隔をあけ、結果を数分キャッシュします）。
- プロフィールは、tikwm が使えないときは tiktok.com の公開ページからも読み取ります。
- 動画ファイルはサーバー（`/api/download`）が中継して、ファイル名つきで保存させます。中継先は TikTok／tikwm の配信元ドメインだけに制限しています。
- **Cookie なし・解析ツールなし・外部スクリプトなし**。ログインはブラウザ標準の「Basic認証」（ブラウザが ID/パスワードを覚える仕組み）です。
- 検索エンジンには載りません（`robots.txt` で全拒否＋`noindex`）。

## 自分のパソコンで動かす

```bash
cd tiktok-research
npm install
cp .env.example .env.local   # APP_USER / APP_PASSWORD を好きな値に変更
npm run dev                  # http://localhost:3000 を開く
```

TikTok に接続せずに画面だけ確認したいときは、`.env.local` に `TT_MOCK=1` を書くとサンプルデータで動きます。

検査コマンド：`npm test`（入力の読み取り・分析計算のテスト）、`npm run lint`、`npm run build`

## 公開（ラウンチ）手順 — Vercel（無料プランで可）

1. https://vercel.com に GitHub アカウントでログイン
2. 「Add New… → Project」→ `family-sns` リポジトリを「Import」
3. **Root Directory** の「Edit」で `tiktok-research` を選ぶ（Framework は自動で Next.js になります）
4. **Environment Variables** に次の2つを追加
   - `APP_USER` … ログインID（例：`me`）
   - `APP_PASSWORD` … 長くて推測されにくいパスワード
5. 「Deploy」を押す → 数分で `https://〇〇.vercel.app` が発行されます
6. 発行されたURLを開き、ID/パスワードを入力して使います（ブラウザに保存すれば次回から入力不要）

> 家族SNS（ルートのプロジェクト）とは別の Vercel プロジェクトになります。お互いに影響しません。
> `APP_PASSWORD` を設定し忘れると、本番では安全のため全ページが「503」になります。

### 公開後の確認

- パスワードなしで開くと「ログインが必要です」になること
- 有名アカウント（例：`khaby.lame`）でプロフィール・投稿一覧が出ること
- 投稿の保存ボタンで mp4 が保存されること

### うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| 「混雑しています」「Free Api Limit」 | 無料APIの回数制限です。数秒待ってもう一度。全件読み込みは自動で間隔をあけます |
| 「見つかりませんでした」 | ユーザー名の綴り、またはアカウントが削除・BANされていないか確認 |
| 保存が途中で失敗する | プレビュー画面の「直接開く」で配信元のファイルを直接開き、ブラウザの保存機能で保存 |
| どの取得もできない | 取得元（tikwm.com）が Vercel のサーバーからの接続を拒否している可能性。別リージョン（Settings → Functions → Region）に変えるか、自宅PC等で `npm run build && npm start` して使う |

## 注意

公開アカウントの公開情報のみを扱います。保存した動画は個人的な視聴・研究の範囲で使い、再配布・再投稿はしないでください（著作権は投稿者にあります）。TikTok の利用規約も確認のうえ、自己責任で利用してください。
