Gemini API 設定（高精度翻訳）

API キーは Google AI Studio で取得できます。キーはこの PC の Chrome（chrome.storage.local）にのみ保存され、Gemini API への通信にだけ使用されます。

セブアノ語は Chrome の音声認識で未対応の場合があり、その場合は fil-PH / en-US で代替認識します。Gemini API キーを設定すると、相手のセブアノ語は Gemini が音声から直接認識・翻訳します。

自分と相手の言語が同じため、認識結果をそのまま表示します。
